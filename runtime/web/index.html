人像和动漫头像会先用分层模型分出背景、身体、皮肤、五官、头发（上传后先显示分层预览）， 画完可以「重画头发」换发色；其他图片按颜色分层，只能临摹，不能按层编辑。
临摹：把图拆成高斯笔画和线条再一笔笔画出来，什么图都行（约 10–15 秒）。 起稿＋续画：只拆出草稿，剩下的由模型按上面的描述画，只适合人像和动漫头像，其他图片会画乱。
